National Statistics Office of Auralia: the country's figures in one place — GDP, prices, jobs, population and the eight regions, with charts, sortable tables, a release calendar and CSV downloads. Auralia is a fictional country; every figure is the site's own internally consistent dataset. The site is plain static files (HTML, CSS, vanilla JS, hand-drawn SVG charts), runs offline in a desktop or phone browser with no network request, and `main.ts` hands it in with its screenshots and dossier.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or hand it in exactly as the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
